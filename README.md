# Рабочая визитка — Евгения Целикина

Минимальный статический сайт в стиле [ENJIGIRLING](https://vremennobeznika.github.io/enjigirling/): нейтральная палитра, карточки, адаптивная сетка, светлая/тёмная темы.

## Что находится на странице

- Краткий профессиональный профиль и направления работы.
- Проекты: портфолио, инженерный справочник, Telegram-канал.
- Контакты: Telegram и электронная почта.

Все исходные контакты и адреса проектов сохранены. Содержание редактируется в index.html; оформление — в style.css; переключатель темы — в script.js. Favicon локальный. Нет фреймворков, сборки, трекеров или обязательных внешних запросов. На основной платформе ENJIGIRLING и здесь используется один ключ localStorage — theme (оба сайта должны открываться на одном github.io-хосте).

## Проверка

Для локальной проверки требуется Node.js 20+:

    node tests/site-check.cjs

GitHub Actions запускает эту проверку при push и pull request. Она проверяет структуру, контакты, локальные ссылки и настройки темы; это не полноценное визуальное или браузерное тестирование.

## Публикация

Для публикации из этого репозитория откройте **Settings → Pages** и проверьте:
- Source: **Deploy from a branch**.
- Branch: **main**.
- Folder: **/(root)**.

Если публикация включена и не используется пользовательский домен, ожидаемый адрес проекта: https://vremennobeznika.github.io/visit_card/ . Фактический адрес и статус нужно сверять в настройках Pages. Не создавайте второй деплой через Actions без необходимости.

## Поддержка

1. При изменении Telegram, почты или портфолио обновите index.html и тест в tests/site-check.cjs.
2. Не добавляйте внешние аналитические скрипты без отдельного решения о приватности и целях измерения.
3. После изменения вёрстки проверьте ширины 320, 375, 768 и 1280 пикселей и работу переключателя темы в браузере.
